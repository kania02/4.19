- Di Codespaces tidak ada adb. Flash/tarik boot dilakukan user dari Windows cmd saat HP berada di OrangeFox (OFox).

- Sebelum edit file baru/berikutnya, ikuti aturan backup repository: cp --update=none file file.bak_<kode>. Jangan mengubah atau menghapus backup yang sudah ada.
- Hindari tes HP yang sangat lama tanpa alasan. Setelah adb muncul, ambil dmesg lebih awal (sebelum kira-kira 100 detik) karena ring buffer cepat tertimpa.

- Aturan user: berhenti setelah tiga trial gagal untuk satu perubahan.

LANGKAH LANJUT YANG DISARANKAN
1. Jangan build ulang br5 kecuali ada perubahan baru; image sudah terbukti dibuat. User perlu mengunduh boot_k419_br5.img dan memutuskan kapan mengujinya.
2. Sebelum flash, pastikan file di PC punya ukuran 25.165.824 byte dan MD5 cdf3b02dc8a11192b53327249e74a20e.
3. Jika br5 diuji, pastikan boot/recovery dan layar/sentuh berfungsi; kumpulkan dmesg/logcat segera setelah adb terdeteksi. Jangan menyimpulkan stabilitas atau perbaikan SSRM/baterai sebelum tes.
4. Sesudah build sukses, ikuti instruksi repo untuk menyimpan konfigurasi hasil build (backup out/.config dan savedefconfig). Jangan commit/push tanpa memastikan cakupan perubahan dan instruksi terbaru.
5. Untuk nama kernel tanpa port-bootstrap, ubah CONFIG_LOCALVERSION hanya setelah dikonfirmasi sebagai perubahan tersendiri, lalu gabungkan dengan perubahan CONFIG lain sebelum build berikutnya.
6. Setelah br5 diuji, lanjutkan diagnosis SSRM/OPP GPU, battery/thermal sysfs, hang acak, navbar/provisioned, PMIC, RTC, dan eMMC berdasarkan data aktual—bukan asumsi.
